# Judgement — Claude Code Context

Judgement is a macOS menu-bar app plus a small CLI that stores human-approved
engineering guidance ("items") and recalls it for coding/review agents. Spec:
Judgement TDD 0.2. Tauri 2 (Rust) shell, React 19 + TypeScript + Vite UI, one
SQLite file shared by the app and the CLI. No server.

## Commands

```bash
npm start                # tauri dev (builds the debug CLI first)
npm test                 # Vitest UI tests
npm run test:types       # tsc --noEmit
npm run lint             # biome check (lint:fix to auto-fix)
npm run test:rust        # cargo test --workspace (also regenerates src/bindings)
npm run lint:rust        # cargo fmt --check + clippy -D warnings
npm run cli              # build + stage the CLI as Tauri's externalBin
```

Before committing, all must be green: `npm test`, `npm run test:types`,
`npm run lint`, `npm run test:rust`, `npm run lint:rust`.

## Layout

```
src-tauri/
  Cargo.toml          # workspace root + the app crate (judgement-app)
  core/               # judgement-core: schema, migrations, validation, unsafe check,
                      # every store op, and the `judgement` CLI binary. NO Tauri dependency.
    migrations/       # versioned SQL; PRAGMA user_version = number of migrations
    prompts/          # analyzer.md — provider-neutral inception-mode prompt
    src/bin/judgement.rs  # CLI: status, list, get, propose (+ hidden `hook`)
    tests/            # ops.rs (temp DB), cli.rs (real binary, temp store)
  src/                # app: tray, window, commands, store watcher, CLI symlink
src/                  # React UI (Learnings, Knowledge, Combine, Edit, Settings)
  bindings/           # GENERATED by ts-rs on `cargo test` — do not edit
  lib/api.ts          # typed invoke wrappers — the ONLY path to Tauri commands
skill/judgement/SKILL.md  # agent skill, hand-installed into ~/.agents/skills
```

## Rules

- **Nothing writes to the store except through `judgement_core::ops`.** The app
  never writes SQL itself.
- **Only the app migrates.** The CLI refuses on schema mismatch.
- **Writes use `BEGIN IMMEDIATE`**; agent-facing ops read `settings` in the same
  transaction as their work (Pause is linearizable across processes).
- **Every text field of every write goes through `validate` / `safety`.**
- **The CLI must not link Tauri.** Check with
  `cargo tree -p judgement-core -e normal --features cli`.
- **The CLI has no confirm/edit/delete.** Those are human-only, in the window.
- **DTO changes:** edit the Rust struct, run `npm run test:rust`, commit the
  regenerated `src/bindings/*.ts`.
- **New Tauri command:** add to `commands.rs`, `generate_handler!` in `lib.rs`,
  and `src/lib/api.ts`.
- **No optimistic success** for pause, confirm, combine, or delete; mutations
  refetch after commit (`useStoreMutation`).
- **No network calls** from the app; links in rendered Markdown are inert.
- Never edit `~/.agents`, `~/.claude/settings.json`, or shell profiles from code.
